# Объекты на карте

Страница `/construction-map`, вход с главной, полного меню и футера.
На главной встроена та же карта, что на отдельной странице; на странице карта
выше, а внизу — форма «Съездим на объект вместе» (тип формы `objects`, в amoCRM —
«Запрос экскурсии на объект»).
Используется JavaScript API Яндекс Карт 2.1. До добавления ключа показывается
встроенная Яндекс Карта области (iframe): её можно двигать и масштабировать,
но отметки из CRM в ней не отображаются. Карточки доступны через список.
После добавления ключа включается API с отметками объектов, фильтрацией и
открытием карточки по нажатию.

Как устроена карта:

- Логотип, копирайты и кнопка «Открыть в Яндекс Картах» не перекрываются.
- Отметки: построенный дом — зелёный знак Деревяги, стройка — светлая отметка
  со знаком в виде каркаса (`public/brand/derevyaga-frame.svg`).
  Близкие дома собираются в кластер с числом домов.
- Без фотографий карточка показывает фирменную заглушку: знак Деревяги
  у готового дома, каркас у стройки.
- Esc закрывает карточку дома.
- Наведение на карточку в списке подсвечивает дом на карте и наоборот.
  На телефоне лента карточек ведёт за собой карту.
- Колесо мыши прокручивает страницу; масштаб — кнопками, Ctrl + колесо
  или щипком тачпада. На телефоне страница листается одним пальцем,
  карта двигается двумя.
- API карт загружается, только когда блок подъезжает к экрану.
- Пока в CRM нет опубликованных объектов, на карте показаны города со
  страницами «Каркасные дома в …» (координаты — в `src/content/cities.ts`).

Ссылка на конкретный дом: `/construction-map?object=ID`, где ID — номер элемента
списка в amoCRM. Кнопка «Поделиться» в карточке копирует такую ссылку, а на
телефоне открывает системное меню. В превью мессенджеров попадают название,
описание и первая фотография дома.

## Подключение Яндекс Карт

1. Войти в https://developer.tech.yandex.ru/ под аккаунтом компании.
2. Нажать «Подключить API», выбрать **JavaScript API** и бесплатный тариф,
   ознакомившись с условиями использования. Геокодер подключается отдельно
   и для текущей реализации не нужен: координаты объектов поступают из CRM.
   Лимит 100 вызовов в сутки относится к панорамам, которые карта не использует.
   Сохранять видимыми логотип Яндекса, копирайты и кнопку «Открыть в Картах».
3. Скопировать API-ключ. В его настройках ограничить использование HTTP
   Referer доменами сайта: `derevyaga.vercel.app`, рабочим доменом и,
   на время разработки, `localhost` / `127.0.0.1`.
4. Локально создать `.env.local` (не добавлять в Git):
   `NEXT_PUBLIC_YANDEX_MAPS_API_KEY=ваш_ключ`
5. Перезапустить `next dev`. В Vercel добавить ту же переменную в
   Settings → Environment Variables, затем выполнить новый deployment.
   Значения NEXT_PUBLIC_* подставляются при сборке, поэтому одной записи
   переменной для уже собранного сайта недостаточно.
6. После активации ключа проверить: карта загрузилась, отметка открывает
   карточку, фильтры скрывают ненужные статусы. Для локальной проверки
   использовать `/construction-map?demo=1`.

Ключ Яндекс Карт предназначен для браузера и виден посетителям — его защита
обеспечивается ограничениями доменов. Токен amoCRM остаётся только на сервере.
Не создавать новый ключ amoCRM вместо ключа Яндекс Карт.
Официальная инструкция: https://yandex.ru/dev/jsapi-v2-1/doc/ru/

## Однократное подключение amoCRM

1. В окружении сервера задать `AMO_DOMAIN`, `AMO_TOKEN` с правами администратора
   списков, `AMO_ADMIN_SECRET`. Секреты не передавать в клиентский код.
2. Отправить POST `/api/internal/amocrm/map-fields` с заголовком
   `x-admin-secret`, равным `AMO_ADMIN_SECRET`. Пустое тело.
   Команда создаёт список «Объекты на карте» или использует существующий
   с этим именем; добавляет только недостающие поля. Никаких объектов не создаёт.
3. В ответе взять `catalogId`, записать в `AMO_MAP_CATALOG_ID` локально
   и в Vercel → Settings → Environment Variables. Перезапустить/пересобрать сайт.
4. В amoCRM → Списки → Объекты на карте добавить элемент и заполнить поля ниже.

В этом окружении ключей amoCRM нет: список в живом аккаунте ещё не создан.

## Работа менеджера

| Поле | Что вводить |
|---|---|
| Название элемента | Публичное название, например «Дом 86 м² в Рощино» |
| Публиковать на сайте | Включить после проверки данных; выключить, чтобы скрыть |
| Статус объекта | Строится / Построен |
| Широта / Долгота | Десятичные координаты, например 60.25 / 29.61. Допустима запятая. В Яндекс Картах: правый клик по месту → «Что здесь?» → скопировать координаты. Пару «60.2555, 29.6030» можно вставить целиком в «Широту», оставив «Долготу» пустой |
| Населённый пункт | Публичное местоположение |
| Описание | Описание дома и хода строительства |
| Выполненные работы | Каждая работа на новой строке |
| Фотографии | Прямые публичные HTTPS-ссылки на изображения, каждая с новой строки, до 20 |
| Стоимость, ₽ | Публичная стоимость; пусто — цена скрыта |
| Площадь, м² | Площадь; пусто — скрыта |
| Год сдачи | Только для построенных домов, например 2025 |
| Проект на сайте | Ссылка на страницу проекта из каталога (или её окончание, например `roshchino-86`). В карточке появится переход к проекту |

Два последних поля необязательные и появились позже остальных: если список уже
создан, повторите POST `/api/internal/amocrm/map-fields` — команда добавит
только недостающие поля.

Первая фотография — обложка. Ссылки должны открываться без входа в amoCRM;
вложения с авторизацией не подходят. Публичные ссылки Яндекс Диска и Google
Диска ведут на страницу просмотра, а не на картинку, — тоже не подходят.
Варианты: публичный бакет S3 (Yandex Object Storage, Selectel) или файлы
в `public/photos/objects/` сайта со ссылками вида `/photos/objects/имя.webp`
(появятся после выкладки сайта). Когда Content-Security-Policy перейдёт
из Report-Only в боевой режим, добавьте домен хранилища в `img-src`. Публикуйте только согласованные с владельцами
фото, координаты и суммы; ФИО, телефоны и другие поля CRM сайт не запрашивает.
Поля незнакомых типов и неполные записи не публикуются. Для координат можно
указать согласованную приблизительную точку вместо точного адреса участка.

Обновление после изменения записи: примерно 5 минут, при следующем запросе
страницы (кэш Next.js может сначала вернуть предыдущую версию). Обновить
вкладку сайта для получения изменений. Отдельный вебхук не требуется.
При ошибке CRM показывается сообщение о недоступности; вымышленные дома не
подставляются. Пустой список отображает честное пустое состояние.

## Проверка

Только при `next dev`: `/construction-map?demo=1` показывает десять явно
подписанных демонстрационных объектов (`src/lib/construction-demo.ts`).
В production параметр игнорируется.
Тесты парсинга: `node --import tsx --test tests/construction-map.test.ts`.

API: https://www.amocrm.ru/developers/content/crm_platform/catalogs-api
Поля: https://www.amocrm.ru/developers/content/crm_platform/custom-fields
