# Изображения конфигуратора: утверждённые размеры и варианты

## Набор

Каталог: `public/constructor/approved-variants-v1/`.
Просмотр: `/constructor/approved-variants-v1/index.html`.
Полный список файлов с размерами: `catalog.json` в каталоге изображений.

Пять утверждённых геометрий: 6×6, 6×8, 6×10, 8×8, 8×10. Первое число — ширина переднего фасада с входом, второе — глубина вдоль правой боковой стены. Фронтон над входом, конёк направлен в глубину.

Для каждого размера подготовлены:

- `base.png` / `.webp`: исходный дом, деревянный фасад, терраса, чёрные металлические сваи; кровля на исходном изображении фальцевая, поэтому для опции «Металлочерепица» нужен именно `roof-metal`.
- `foundation-concrete`: железобетонные сваи.
- `roof-ondulin`, `roof-metal`, `roof-shingles`: ондулин, металлочерепица и мягкая черепица.
- `facade-painted`, `facade-planken`: горизонтальная имитация бруса цвета мха и вертикальный планкен.
- `terrace-no`: дом без открытой террасы, с небольшой входной площадкой и ступенями.

В `details/` находятся три иллюстративных разреза стены: `insulation-100`, `insulation-150`, `insulation-200`. Это визуальные образцы, не рабочие чертежи. Ячейки каркаса заполнены утеплителем во всех вариантах.

Всего 43 выбранных изображения: 5 исходных домов, 35 вариантов домов и 3 разреза стены. Из них 37 новых изображений созданы в пакетном проходе; фундамент 6×6 был создан и показан ранее. Две дополнительные генерации исправили лишнее фронтальное окно у домов 6×8 и 6×10 без террасы. Первые версии и исправления сохранены в `revisions/`.

## Генерация и исходники

Использован встроенный imagegen. Каждое изображение сгенерировано отдельным запросом от утверждённого дома соответствующего размера; варианты материалов не создавались последовательно друг из друга. Исключение — локальное удаление лишнего окна в двух вариантах без террасы.

`plan.json` содержит полный первоначальный набор промптов. `generation-log.json` содержит выполненные запросы, референсы, пути исходников imagegen и сохранённых PNG, включая исправления. Рядом с каждым вариантом находится JSON его запроса. Для двух исправленных `terrace-no` финальный промпт находится в `revisions/<размер>-terrace-no.json`; история первого прохода сохранена рядом с основным изображением.

Утверждённые исходные изображения остаются в `public/constructor/approval-reference/` и не изменены.

PNG домов: **1536×1024 px**, пропорции **3:2**. WebP подготовлены без изменения размеров, quality 94. Размеры квадратных разрезов записаны в `catalog.json`. Для Photoshop открывать PNG. Размерные подписи уже включены в изображения домов.

## Проверка и подключение

`scripts/prepare-approved-variants.mjs` копирует утверждённые исходники, конвертирует финальные PNG в WebP и формирует каталог. `alignment-audit.json` содержит поиск смещения по неизменяемой области стен для вариантов кровли и фундамента; найденное смещение 0–1 px. Этот тест не гарантирует полного совпадения всех пикселей: текстуры, свет и мелкие детали после генерации могут отличаться.

`scripts/check-approved-variants.mjs` проверяет загрузку 43 изображений, размеры окна 360/390/768/1280 px, переключение исходника/варианта, прозрачность сравнения и скачивание PNG. Результат — `review-checks.json`.

Текущий проход готовит набор и страницу просмотра. Многослойное соединение новых изображений с рабочим калькулятором ещё не подключено. Старые маски `sceneGeometry` из `layers-v3` относятся к другой геометрии и для этих изображений не подходят. При подключении нужно определить новые маски, отдельно учесть передний фасад и сваи дома без террасы, сохранить выбранную кровлю поверх смены фасада и не выводить вторую копию размерных линий. Цены, API и комплектации не изменены.
