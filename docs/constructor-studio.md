# Калькулятор: шесть разделов в интерфейсе по референсу

Референс: предоставленный скриншот dom.tn.ru/calculator/facade (интерактивный сайт при исследовании не загрузился). Адаптированы визуальная иерархия и компоновка под существующий ассортимент Деревяги.

- Прямой переход между шестью разделами: Размер дома, Фундамент, Каркас и утепление, Кровля, Фасад, Терраса.
- Панель выбора слева, крупная закреплённая при прокрутке сцена справа; компактная шапка, зелёные активные вкладки, карточки материалов.
- По умолчанию показан весь готовый дом с текущими параметрами. Режим Конструктив использует существующие стадии для активного раздела.
- Доставка сохранена раскрывающимся пунктом у стоимости, без седьмой основной вкладки.
- Сохранены материалы, цены, ипотека, формы и идентификаторы amoCRM. Индивидуальный размер отображается как пример с ценой По запросу.
- На телефоне шесть вкладок в два ряда, ниже модель и настройки. Уменьшенная анимация учитывается.

Проверено: 360/390/768/1280 px без переполнения, все шесть вкладок, клавиатурное переключение, смена фасада и стоимости, режимы фундамента/каркаса, удаление террасы, индивидуальный размер. Тесты расчёта покрывают 540 стандартных комбинаций; все шесть тестов прошли. Реальные заявки не отправлялись.

## Уточнения оформления
Возвращён фирменный PageHero на серой панели. Удалён переключатель режима: модель всегда следует конструктивной стадии активного раздела. Камера учитывает выступы до 1,1 м по контуру и безопасный коэффициент 1,06, вместо приближения 0,9. Ипотечный блок переработан: двухцветный заголовок, программы с выбранным состоянием, итоговая панель #4e6254, компактные пропорциональные цифры без межбуквенного и межсловного разрежения. Проверены переключение программ, конструктив и отсутствие переполнения на 360, 768 и 1280 px. ESLint, production build и шесть тестов конструктора прошли.

## Уточнение сцены и шрифтов
Числовые суммы используют штатный Inter через --font-sans. Размерные подписи прозрачные, выполнены Inter и ориентируются по проекции соответствующих линий при вращении камеры. Canvas занимает всю плашку без внутренних рамок; заголовок и кнопки поверх модели. Удалена подпись конструктивного раздела, исходная камера приближена (коэффициент 0,99). ESLint, production-сборка и 6 тестов конструктора проходят.
