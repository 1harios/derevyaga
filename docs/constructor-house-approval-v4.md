# Согласование домов — версия 4

Статус: отдельный эскиз 6×6 для согласования. На сайт не подключён. Остальные размеры и варианты материалов готовятся после согласования пропорций.

Первая цифра — ширина фасада с входом, вторая — глубина корпуса. Для 6×8 и 6×10 увеличивается глубина. Сохраняются растительность, фон без неба, естественный свет и размерные линии без белых плашек.

6×6: более широкий по восприятию фасад, окно рядом с входом, умеренная высота фронтона, неглубокая терраса. Изображение является визуальным эскизом, а не рабочим чертежом.

Генерация: встроенный imagegen. Промпты и исходные пути записаны в `public/constructor/approval-v4/generation.json`. Итог: `public/constructor/approval-v4/house-6x6.png`.
